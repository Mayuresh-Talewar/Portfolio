# Direction reset notes (CD-002, stopped 2026-10-02)
Why the style tile read as a "web template dressed as manga" (input for the One Piece reset):
1. It was built from stacked sections and specimen boxes. Real manga is a page-turn rhythm of whole spreads with one dominant panel per page, so compose the mockup as PAGES.
2. There was no drawn art. CSS focus lines, a clip-path star and dots can't carry a cover; it needs a drawn focal image.
3. Lettering and rough frames were applied on top of a perfect 12-column grid. In real manga the art drives the panels and bubbles overlap the art.
4. The type hierarchy was web-UI: the obi block outweighed the name and there were mono meta tags everywhere. Covers use a big custom logotype lockup.
5. Laptop-UI screenshots in panels read as a portfolio card grid, and Shadow Monarch's UI is violet. Draw them as in-world objects, or print them as an ink + cyan duotone.
6. The research leaned on generic anti-slop lists. Derive the rules from real tankōbon covers, Jump layouts and the official One Piece sites (see 08-reference-analysis.md).
